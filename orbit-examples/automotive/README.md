# Automotive Industry Examples

This directory contains Orbit-RS examples for the **Automotive Industry**, demonstrating connected vehicle platforms, retail operations, and fleet management.

## Scenarios

### 1. Connected Vehicle Platform
**Directory**: [`connected_vechicle_platform/`](connected_vechicle_platform/)
-   **Description**: Ingesting high-velocity telemetry from vehicles, managing fleet status, and supply chain tracking.
-   **Protocols**: SQL, CQL (Cassandra), Redis, AQL (ArangoDB).

### 2. Car Rental Agency
**Directory**: [`car_rental_agency/`](car_rental_agency/)
-   **Description**: Complete rental management system including bookings, inventory, and real-time availability caching.
-   **Protocols**: SQL, Redis.

### 3. Automotive Retailer (Dealership)
**Directory**: [`automotive_retailer/`](automotive_retailer/)
-   **Description**: Vehicle sales, inventory management, and Customer 360 views.
-   **Protocols**: SQL, MongoDB.

### 4. Ride Hailing & Robo Taxi
**Directory**: [`ride_hailing/`](ride_hailing/)
-   **Description**: Real-time fleet tracking, trip ledgers, and driver management.
-   **Protocols**: MongoDB, SQL.

### 5. Car Sharing (Peer-to-Peer & Fleet)
**Directory**: [`car_sharing/`](car_sharing/)
-   **Description**: Membership plans, hourly bookings, and vehicle IoT lock state.
-   **Protocols**: SQL, Redis.

## Getting Started

Each directory contains its own README with specific instructions on how to run the examples.
