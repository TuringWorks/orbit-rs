# Commercial Airline Operations

Examples for **Maintenance, Repair, and Overhaul (MRO)** and **Flight Data Analysis**.

## Scenarios

### 1. MRO System (SQL)
**File**: [`sql/01_mro_system.sql`](sql/01_mro_system.sql)
- Managing fleet maintenance schedules, AOG (Aircraft on Ground) events, and parts inventory.

### 2. Flight Data Logs (MongoDB)
**File**: [`mongodb/02_flight_logs.js`](mongodb/02_flight_logs.js)
- Analysis of unstructured flight recorder data (events, fuel stats, engine parameters).
