# Orbit Compatibility Layer

This directory contains compatibility checks and tests for various protocols supported by Orbit.
Each subdirectory corresponds to a specific protocol and contains tests to verify compliance and compatibility.

## Supported Protocols

- **PostgreSQL**: SQL compatibility checks.
- **AQL**: ArangoDB Query Language compatibility.
- **CQL**: Cassandra Query Language compatibility.
- **Neo4j**: Cypher/Bolt protocol compatibility.
- **MongoDB**: MongoDB wire protocol compatibility.
- **MySQL**: MySQL wire protocol compatibility.
- **Redis**: RESP protocol compatibility.
- **OrbitQL**: Native OrbitQL compatibility.
